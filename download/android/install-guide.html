نصب مطمئن Lexa روی اندروید

چون Lexa بیرون از گوگل‌پلی توزیع می‌شود، Play Protect پیش از نصب پیام «تأیید نشده» نشان می‌دهد. این یک هشدار معمول برای همهٔ اپ‌های خارج از پلی‌استور است، نه نشانهٔ ویروس — با ۴ گام زیر خیال راحت نصب کن.

۱

فایل را فقط از منبع رسمی بگیر

فایل Lexa-0.10.3-android.apk را از صفحهٔ ریلیز رسمی گیت‌هاب (pvwvuow/lexa) یا لینکی که خود تیم می‌فرستد دانلود کن؛ فایل را از کانال‌های ناشناس برندار.

۲

اجازهٔ نصب را یک‌بار بده

اولین نصب، اندروید می‌پرسد: «اجازهٔ نصب از این منبع؟» → روی فایل‌منیجر یا مرورگرِ دانلود Allow from this source را بزن. فقط یک‌بار لازم است.

۳

اگر Play Protect هشدار داد

روی پیام، More details را بزن و گزینهٔ Install anyway / نصب بدون اسکن را انتخاب کن. امضای رسمی اپ سالم است؛ هشدار فقط به‌خاطر خارج‌بودن از پلی‌استور است.

۴

آپدیت‌های بعدی داخل خود اپ است

برای نسخه‌های بعدی لازم نیست دوباره APK نصب کنی؛ از تنظیمات ← بررسی به‌روزرسانی داخل خود Lexa، فقط فایل‌های تغییرکرده نصب می‌شود.

چرا می‌شود اعتماد کرد؟

اپ فقط یک مجوز می‌خواهد (اینترنت)، ترافیک صرفاً رمزنگاری‌شده (HTTPS) است، و هر نسخه با همین یک کلید رسمی امضا شده. اگر خواستی اصالت فایل را دقیق چک کنی، SHA-256 آن را با checksums.txt کنار ریلیز مقایسه کن — اثر انگشت امضای رسمی:
